=================================================================
   DEPLOYMENT STEPS (3 EASY STEPS)
=================================================================

OPTION A: ONE-CLICK DEPLOYMENT (RECOMMENDED)
─────────────────────────────────────────────
1. Double-click: 00-Complete-Setup.bat
2. Wait for completion (5-10 minutes)
3. Open browser: http://localhost:5173

OPTION B: STEP-BY-STEP DEPLOYMENT
─────────────────────────────────
Step 1: Install Dependencies
   • Double-click: 01-Install-Dependencies.bat
   • Wait for npm install to complete
   • This installs all backend and frontend packages

Step 2: Setup Database
   • Double-click: 02-Setup-Database.bat
   • Creates 'pos' database in PostgreSQL
   • Sets up 12 tables with indexes
   • Creates default users and settings

Step 3: Start Servers
   • Double-click: 03-Start-Servers.bat
   • Opens 2 terminal windows (Backend + Frontend)
   • Wait for both to show "ready" message
   • Open browser: http://localhost:5173

=================================================================
   TROUBLESHOOTING
=================================================================

Problem: PostgreSQL Connection Failed
Solution:
   1. Check if PostgreSQL service is running
   2. Verify password is: Black@786##
   3. Ensure PostgreSQL is in system PATH

Problem: Port Already in Use
Solution:
   • Run 03-Start-Servers.bat again (kills existing processes)
   • Or manually close Node.exe in Task Manager

Problem: Dependencies Not Installing
Solution:
   1. Check internet connection
   2. Run as Administrator
   3. Clear npm cache: npm cache clean --force

Problem: Database Setup Fails
Solution:
   1. Ensure PostgreSQL is running
   2. Check admin privileges
   3. Verify password matches configuration
