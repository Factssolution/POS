## 📋 Step-by-Step Deployment Instructions

### Step 1: Create Render Account

1. Go to: **https://render.com**
2. Click **"Get Started for Free"**
3. Sign up with your GitHub account (recommended)
4. Complete registration

---

### Step 2: Connect GitHub Repository

1. After login, click **"New +"** → **"Blueprint"**
2. Connect your GitHub account if not already connected
3. Select repository: **`Factssolution/POS`**
4. Render will automatically detect `render.yaml`

---

### Step 3: Apply Blueprint

1. Render will show all services from `render.yaml`:
   - **pos-backend** (Node.js API)
   - **pos-frontend** (React Frontend)
   - **pos-database** (PostgreSQL)

2. Click **"Apply"** to create all services

---

### Step 4: Configure Database

Render will automatically create PostgreSQL database with:
- **Database Name:** `pos_system`
- **Username:** `pos_admin`
- **Password:** Auto-generated (Render will show this)
- **Host:** Auto-generated (e.g., `dpg-xxxxx.oregon-postgres.render.com`)
- **Port:** `5432`

**⚠️ IMPORTANT:** Save these credentials!

---

### Step 5: Update Backend Environment Variables

1. Go to **Dashboard** → **pos-backend** → **Environment**
2. Add these environment variables:

```
DB_HOST=<Your PostgreSQL Host from Step 4>
DB_PORT=5432
DB_NAME=pos_system
DB_USER=pos_admin
DB_PASSWORD=<Your PostgreSQL Password from Step 4>
NODE_ENV=production
PORT=5001
JWT_SECRET=<auto-generated by Render>
SESSION_SECRET=<auto-generated by Render>
TZ=Asia/Karachi
CORS_ORIGIN=<Frontend URL - will be added in Step 6>
```

3. Click **"Save Changes"**

---

### Step 6: Get Frontend URL & Update Backend

1. Go to **Dashboard** → **pos-frontend**
2. Copy the service URL (e.g., `https://pos-frontend-xxxx.onrender.com`)
3. Go back to **pos-backend** → **Environment**
4. Update `CORS_ORIGIN`:

```
CORS_ORIGIN=https://pos-frontend-xxxx.onrender.com
```

5. Click **"Save Changes"**

---

### Step 7: Update Frontend Environment Variables

1. Go to **Dashboard** → **pos-frontend** → **Environment**
2. Add this environment variable:

```
VITE_API_URL=https://pos-backend-xxxx.onrender.com
```

(Replace with your actual backend URL)

3. Click **"Save Changes"**

---

### Step 8: Deploy Database Schema

**Option A: Using Render's Web Shell (Recommended)**

1. Go to **pos-backend** → **Shell**
2. Wait for shell to load
3. Run these commands:

```bash
# Install psql client
apt-get update && apt-get install -y postgresql-client

# Run database schema
psql -h $DB_HOST -U $DB_USER -d $DB_NAME -f database-schema.sql

# Seed initial data
cd src/backend
node scripts/seed.js

# Create admin user
node scripts/create-user.js
```

4. Enter database password when prompted

**Option B: Using Local Machine**

1. Install PostgreSQL client locally
2. Run:

```bash
psql -h <DB_HOST> -U pos_admin -d pos_system -f database-schema.sql
```

---

### Step 9: Verify Deployment

1. **Backend Health Check:**
   ```

   ```
   Should return:

2. **Frontend:**


3. **Login:**

   - Password: `admin123` (or check seed.js output)

## 🔧 Post-Deployment Configuration

### Update API Service URL in Frontend

If API calls fail, check:

1. **Frontend `.env` or Environment Variables:**
   ```
   VITE_API_URL=https://pos-backend-xxxx.onrender.com
   ```

2. **Backend CORS:**
   ```
   CORS_ORIGIN=https://pos-frontend-xxxx.onrender.com
   ```

3. **Rebuild Frontend:**
   - Go to **pos-frontend** → **Manual Deploy** → **"Deploy latest commit"**

## 🌐 Custom Domain (Optional)

### For Frontend:

1. Go to **pos-frontend** → **Settings**
2. Scroll to **"Custom Domains"**
3. Click **"Add Custom Domain"**
4. Enter: `possystem.gt.tc`
5. Update DNS records at your domain registrar:
   ```
   Type: CNAME
   Name: @ or www
   Value: pos-frontend-xxxx.onrender.com
   ```

### For Backend (API):

1. Go to **pos-backend** → **Settings**
2. Add custom domain: `api.possystem.gt.tc`
3. Update DNS similarly

## 🆘 Troubleshooting

### Backend won't start:
```
1. Check logs for errors
2. Verify DB_HOST, DB_USER, DB_PASSWORD are correct
3. Ensure database-schema.sql has been run
4. Check if PostgreSQL is accessible
```

### Frontend can't connect to API:
```
1. Verify VITE_API_URL is correct
2. Check CORS_ORIGIN in backend matches frontend URL
3. Rebuild frontend after changing environment variables
```

### Database connection failed:
```
1. Verify credentials in Environment Variables
2. Check if database schema was created
3. Test connection from backend shell:
   psql -h $DB_HOST -U $DB_USER -d $DB_NAME -c "SELECT 1;"
```

### CORS errors:
```
1. Backend CORS_ORIGIN must include frontend URL
2. Format: https://pos-frontend-xxxx.onrender.com
3. Multiple origins: https://url1.com,https://url2.com
```
